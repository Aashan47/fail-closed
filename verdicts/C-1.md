## Port 18080 teardown symptom

@builder reported that after teardown a probe can return `(56) Recv failure: Connection
reset by peer` rather than exit 7. Reproduced here after my own teardown:

    $ docker ps -a | grep tk-      (none)
    $ lsof -nP -iTCP:18080 -sTCP:LISTEN
    ssh  55038  ...  TCP *:18080 (LISTEN)        (Colima's SSH multiplexer)
    $ curl -fsS -m 5 http://127.0.0.1:18080/health
    curl: (56) Recv failure: Connection reset by peer
    curl exit=56

Both shapes are the same condition — the multiplexer accepting and resetting with no
container behind it. An `until curl -fsS` loop treats 56 and 7 alike, so no Check is
affected. Recorded because a reader seeing 56 where the C-142 verdict records 7 would
otherwise have a discrepancy to explain.
